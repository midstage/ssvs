# Connecting and billing

## What connecting does

The free `ssvs-start-here` skill works on its own. Connecting adds the full SSVS kit: one skill per framework in the book, served live from Midstage so you always have the current version.

## What you need

- **Claude Code.** The kit connects to Claude Code today. Claude Desktop and claude.ai are not supported yet.
- **A GitHub account.** You sign in with GitHub to connect.
- **A subscription.** USD 19 a month, paid through Stripe.

## What we store

- **Your GitHub identity**: your GitHub user id, name and email.
- **Your subscription status**, as reported by Stripe. We never see or store your card details.
- **Which kit tools you use, and when.** We use this to improve the kit.

Your conversations stay in your own Claude. We only receive what Claude sends to the kit's tools, such as which skill to load.

## Cancelling

Cancel any time. Contact us through the email on your Stripe receipt. Access stops when the subscription ends.
